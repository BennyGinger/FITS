# Segmentation overview

[Guide home](README.md)

Segmentation identifies cells/objects in each frame. Choose a target channel and
model, inspect a preview, then run the included step.

- [Segmentation settings](settings/segmentation.md): parameters in the main Process tab.
- [Segmentation preview](tools/segmentation.md): interactive model and mask inspection.
- [Compartment preview](tools/compartments.md): inspect cell/membrane/cytoplasm geometry.
- [Tracking settings](settings/tracking.md): link segmented objects through time.
