# Full Report

[Guide home](../README.md)

Related: [Main GUI](../runs_and_settings.md) · [Troubleshooting](../troubleshooting.md) · [Manage files](manage_files.md)

Open **Full Report** beside the main run-browser title, or double-click a saved report.

| Control / display | What it shows |
| --- | --- |
| Overview | Counts of completed, partial, skipped and failed work by stage, followed by experiment details or report notes. |
| Original text | The underlying plain-text report for copying or inspection. |
| Source / timestamp | The saved report file and creation time when available. |
| Close | Return to the main GUI; reading a report does not rerun processing. |

If no saved report exists, the main GUI explains how to create one. Reports
summarise the run that produced them; use Manage files for current artifact status.
